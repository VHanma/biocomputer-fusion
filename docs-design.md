# Design Notes

## Core abstraction

The project treats a "biocomputer" as a layered simulator:

1. **Storage layer** — digital payloads mapped to A/C/G/T strings.
2. **Signal layer** — RNA-like messages that decay over discrete ticks.
3. **Logic layer** — named boolean gates inspired by gene-circuit diagrams.
4. **State layer** — a cell-state ledger for energy and recyclable byproducts.
5. **Interface layer** — nano-interface read/write/scan controls.
6. **Search layer** — evolutionary optimization over tiny gate programs.
7. **Wave layer** — symbolic modulation and sequence-resonance scoring.

## Wave-field layer

The wave layer is deliberately framed as a computational metaphor. It can be used
for art, speculative visualization, scoring overlays, and alternative program
weighting. It is not represented as proof of biological wave reprogramming.

## Sustainability metaphor

The metabolic state model uses a recyclable byproduct pool. This lets programs
track an energy and waste ledger without implying real cellular thermodynamics.
