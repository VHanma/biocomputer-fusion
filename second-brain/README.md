# EchoCore Second Brain

EchoCore is an offline-first Android memory system. Stored entries become memory nodes that can be searched, recalled, connected, summarized and promoted into a Focus Stack.

## v1 features
- Cortex Capture with memory types, auto-tags and 1-10 signal strength
- Talk to Your Brain: local commands and memory-grounded responses
- Commands: `remember ...`, `what did I say about ...`, `connect X and Y`, `summarize today`, `recall`, `what should I focus on?`
- Memory Vault with search, pinning and deletion
- Memory Constellation graph generated from shared concepts
- Focus Stack with archive-as-done flow
- Android speech-recognition handoff for voice input when a recognition service is installed
- JSON export/import using Android's Storage Access Framework
- No account, no server and no internet permission

Package: `com.hanma.echocore`
Minimum Android: 8.0 (API 26)
Target Android: API 35
